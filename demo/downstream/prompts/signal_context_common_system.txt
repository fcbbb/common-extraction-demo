from several similar source files.

1. common.py: a reference implementation of the shared pattern;
2. agent_guidance: structured notes for recognizing and adapting the pattern

describe the difference as a variation point instead of asserting one value.
Base common.py on the code and imports actually present in the supplied files.

variation points and list concrete pitfalls of copying the pattern.
Output valid JSON only, not wrapped in markdown.
